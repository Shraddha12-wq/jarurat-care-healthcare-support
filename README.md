# 🏥 Jarurat Care – Healthcare Support Web App

Jarurat Care is a responsive healthcare support and volunteer platform designed to connect people who need healthcare-related guidance with volunteers and support services.

## 🌟 Features

- 🏠 Responsive Home Page
- 🧑‍⚕️ Patient Support Request Form
- 🙋 Volunteer Registration Form
- 🤖 Automated FAQ Chatbot
- 📱 Mobile Responsive Design
- ✅ Form Validation
- 💾 Client-side data handling
- 🔗 Easy navigation between pages

## 🤖 AI / Automation Idea

The project includes an automated FAQ assistant that responds to common user questions related to healthcare support, volunteering, services, and emergency information.

The chatbot currently uses keyword-based intent matching and predefined responses.

In the future, it can be enhanced using an AI/NLP API to understand natural-language questions and provide more intelligent responses.

## 🏢 NGO Use Case

This application can help an NGO such as Jarurat Care to:

- Collect patient support requests
- Register volunteers
- Answer frequently asked questions automatically
- Reduce repetitive manual communication
- Provide users with quick access to support information
- Improve communication between volunteers and people seeking help
